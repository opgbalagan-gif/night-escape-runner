# Ночной побег

Играбельный вертикальный 2D endless runner. Один маршрут вдоль ночного средиземноморского побережья, прыжки через препятствия, монеты и преследователи.

Берег и каменная дорога прокручиваются с разной скоростью. ОМОН виден в начале забега, затем отстаёт; каждое столкновение приближает его снова. Под ногами преследователей появляются облачка пыли. Ящик и конус нарисованы как отдельные прозрачные спрайты.

## Запуск

В папке проекта выполните `npm start` или `node server.js`, затем откройте `http://127.0.0.1:4173`.

Управление: **пробел**, **↑**, **W** или касание игрового поля — прыжок; **P** или **Esc** — пауза. На телефоне есть кнопка «Прыжок». Звук включается и выключается кнопкой ♪.

Ящики и конусы нужно перепрыгивать: персонаж отталкивается перед ними, проходит выше их верхней границы и приземляется на дороге за ними. После трёх столкновений преследователи догоняют героя. Рекорд сохраняется локально в браузере.

Таблица рекордов хранит десять лучших забегов на этом устройстве. После проигрыша результат записывается автоматически под последним использованным именем; имя можно изменить на экране «Поймали!», где пять лучших результатов видны сразу без прокрутки. Все десять доступны с начального экрана. Общего сетевого рейтинга между устройствами пока нет.

Игровая анимация бега использует `assets/hero-run.png`. Перед первым забегом показывается найденная копия исходного 14-секундного видеокружка ([публикация источника](https://t.me/streamincube/3915)); круглый фрагмент вырезан из оформления перепоста и немного осветлён. Можно пропустить вступление. На фоне экрана «Поймали!» сразу воспроизводится один из трёх коротких MP4 из [мемного плейлиста](https://www.youtube.com/playlist?list=PLmpjryR_2olUTzMKaVGtBn6RSEc1jvdFc). Зелёный фон удалён и заменён ночным берегом. Оригинальный звук играет один раз, затем видео продолжает крутиться без звука. Поверх него видны результат и таблица рекордов. Отдельные концепт-клипы бега и исправленного прыжка лежат в `art/higgsfield/animations/`.

Голосовые реплики пока отсутствуют: `audio/voice/manifest.json` содержит пустые списки. Игровые события и ограничения частоты воспроизведения готовы к подключению проверенных `.ogg`, когда будут подтверждены права и точные таймкоды.

Исходные запросы для генерации спрайтов препятствий сохранены в `assets/obstacle-prompts.md`. Спрайты созданы встроенным imagegen.
